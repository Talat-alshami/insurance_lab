### 🛠️ 2. العمليات التي أُجريت على البيانات
* فصل البيانات إلى مجموعتين مستقلتين (مدخنين وغير مدخنين).

* إجراء اختبار Levene لفحص تجانس التباين.
* إجراء اختبار Welch's t-test لحساب الفرق بين المتوسطين.
* حساب فترة الثقة 95% (CI) للفرق بين المتوسطين يدوياً.
* التحقق باستخدام اختبار Mann-Whitney U غير المعلمي.
* حساب حجم الأثر (Cohen's d).

### 📊 4. النتائج الأساسية التي تم التحقق منها
* **تجانس التباين:** p-value ≈ 0 (التباينات غير متساوية جذرياً، مما يؤكد إلزامية استخدام Welch بدل Student).
* **اختبار Welch:** t-statistic = 32.74، p-value تقترب من الصفر (فرق دال إحصائياً).
* **فترة الثقة (95%):** الفرق الحقيقي في المجتمع يتراوح بين **$22,190.79** و **$25,028.35**.
* **التحقق (Mann-Whitney U):** p-value ≈ 0 (يتطابق مع Welch، مما يعزز موثوقية النتيجة رغم التواء البيانات).
* **حجم الأثر (Cohen's d):** **3.16** (أثر هائل جداً)، مما يؤكد الأهمية العملية وليس فقط الدلالة الإحصائية.

### 🧠 5. المهارات الرياضية المستخدمة
* اختبارات الافتراضات (Assumption Checks).
* اختبار Levene (Levene's Test for Homogeneity of Variance).

* فترات الثقة للفرق بين المتوسطين (Confidence Interval for Difference in Means).
* الاختبارات اللامعلمية (Mann-Whitney U Test).
* حجم الأثر (Cohen's d for independent samples).
