# Health Insurance Charges - Data Science Project

هذا المستودع يحتوي على مشروع متكامل لتحليل بيانات تكاليف التأمين الصحي وبناء نموذج تنبؤي، وفق منهجية صارمة لتعلم الرياضيات التطبيقية وعلوم البيانات.

## 📂 هيكل المشروع
*   `data/`: البيانات الخام (Raw) والمعالجة (Processed).
*   `notebooks/`: دفاتر Jupyter التي تحتوي على الكود والتحليل.
*   `reports/`: التقارير الاستكشافية والرسوم البيانية.
*   `src/`: الأكواد والوحدات البرمجية القابلة لإعادة الاستخدام.
*   'tests/' اختبار الملفات
